# 开发者端操作教程（v2.7.8）

> **v2.7.4 起界面变化**：左侧是折叠图标栏，鼠标悬停展开（不挤占工作区）；
> 身份改为「玩家 / 开发者」滑动开关；新增「管理」页，集中放全局预设总览、
> 行内检查/更新/发布/绑定、快捷操作、云端文件树和完整日志。
> 设置页改为左侧设置、右侧运行日志两栏。开发者未加载整合包也可以先登录云端。


> 面向：要发布 / 更新枪包预设的人。
> 需要：一个蓝奏云账号（免费账号即可）+ 一个整理好的预设目录。
> 本文同时是**教程动画的脚本**：第 9 节给了分镜建议。

---

## 1. 开始之前

| 名词 | 意思 |
|---|---|
| 云端路径 | 蓝奏云里的文件夹路径，例如 `/PulsesSwap/SSR预设包`，不存在会自动建 |
| manifest | 程序生成的文件清单（`_pulses_manifest.cfg`，内容是 JSON；旧版 `.txt` 仍可读），玩家靠它判断该下什么 |
| generation | 每发布一次 +1，玩家用来判断是不是新版本 |
| 预演 | 只显示"会做什么"，不真的上传 |

发布前请确认：

1. 预设目录里的枪包已经放好（`X.zip` 或 `X/` 文件夹都行）
2. 单个文件 < 100MB（蓝奏免费账号上限）
3. 文件名扩展名在网盘白名单里（`.zip` `.txt` `.cfg` `.jar` 等；**`.json` / `.toml` / `.yaml` 不行**，程序会提前拦住）

## 3. 流程 A：第一次发布

### ① 切换为开发者并认证

1. 点侧边栏底部的 **切换身份**
2. 弹窗「切换为开发者」：
   - **蓝奏账号**：手机号 / 邮箱
   - **密码**
   - 点 **登录并切换**
3. 成功后侧边栏徽标变成「开发者」，下面一行是打码后的账号（如 `186****9816`）

> 账号密码只存在本机（`PulsesSwap_database/.online/account.json`，做了打码处理）。
> 下次启动会自动登录；失败会提示重新认证。

**认证失败对照**：

| 提示 | 原因 |
|---|---|
| 账号或密码为空 | 没填 |
| 登录失败：账号或密码错误 | 填错 |
| 登录失败：账号未激活，请先激活后使用云存储 | 去蓝奏官网激活一次 |
| 连接蓝奏失败 | 网络 |

### ② 绑定云端路径

1. 在卡片上点 **绑定**（或右键 → 云端来源…）
2. 弹窗「云端来源 · <预设名>」：
   - **云端路径**：网盘里的文件夹路径，例如 `test`（就传到根目录的 test 里）
     或 `/PulsesSwap/SSR预设包`（多级目录会自动建）
   - 其他字段（分享链接/密码）开发者不用填
3. 点 **保存**

保存后程序会自动"扫描差异"：读云端 manifest → 和本地比。

### ③ 扫描差异

卡片第三行会变成「**有 N 项待发布**」，圆点变橙并呼吸。

也可以点「检查全部」批量扫描。

### ④ 发布

点卡片上的 **发布**（或右键 → 发布到云端…）：

```
发布 · SSR预设包
云端当前 generation 7，发布后变成 8。

版本号  [v2026.10.18]   更新说明 [新增 3 把枪，修贴图        ]
最低程序版本 [2.5.0]

┌────────────────────────────────────────────┐
│ 上传 3 · 删除云端 1 · 一致 21    [全选][全不选] │
│ ☑ ● gun_alpha.zip          上传    41.9 MB   │
│ ☑ ● gun_gamma.zip          上传    38.0 MB   │
│ ☑ ● gun_new.zip            上传    22.0 MB   │
│ ☐ ○ gun_old.zip        删除云端    18.0 MB   │
└────────────────────────────────────────────┘
                              [取消] [预演] [开始发布]
```

- **版本号**：默认当天日期 `v2026.10.18`，可以改成 `v2.1.0`
- **更新说明**：会显示在玩家同步框里
- **最低程序版本**：可留空；填了以后低于它的玩家会被拦住
- **预演**：只弹一个摘要，不上传
- **开始发布**：真正上传

发布过程中的顺序（很重要，决定"会不会发一半"）：

1. 逐级确保云端文件夹存在（有就复用）
2. 删除勾选的「云端多余」
3. 逐个上传（文件夹型先打包成 `.zip`）
4. **全部成功后才上传新 manifest**（`_pulses_manifest.cfg`，generation +1）
5. 取文件夹分享链接

> manifest 是后缀 `.cfg`、内容为 JSON 的文件，带 `manifest_sha256` 整份校验和 `packed_sha256` 传输包校验；
> 任何一步失败都不会替换 manifest —— 玩家看到的仍是完整的旧版本。

### ⑤ 拿到分享链接

发布成功后弹「发布完成」：

```
发布完成
v2026.10.18 · generation 8 · 105.3 MB

┌──────────────────────────────────────┐
│ https://nimshade.lanzoul.com/b013a3gkpa │
│ 密码：b2ns                            │
└──────────────────────────────────────┘
                            [复制分享信息] [完成]
```

点 **复制分享信息** → 得到「链接 + 密码」，发给玩家即可。

## 4. 流程 B：更新已有预设

1. 改本地枪包（换贴图、加新枪）
2. 点卡片 **发布**（或「检查全部」先看差异）
3. 同步框里只有真正变化的文件（文件夹型枪包只要内容变了就整包重传）
4. 改一下 **版本号** 和 **更新说明** → **开始发布**

> 没变的文件不会重传；但文件夹型枪包的粒度是"整个文件夹"。

---

## 5. 流程 C：删除枪包

1. 本地删掉那个枪包
2. 点 **发布** 前先「检查全部」
3. 差异列表里它变成「**删除云端**」（默认**不勾**）
4. 勾上它 → **开始发布**

不勾就会保留在云端（玩家那边也留着）。

---

## 6. 发布记录

双击卡片 → 详情 → **记录** 标签：

```
v2026.10.18   #8   105.3 MB   2026-10-18 01:20 · 上传 3 项
v2026.10.10   #7    98.1 MB   2026-10-10 22:03 · 上传 2 项
```

每个预设保留最近 20 条。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 「网盘不接受这个扩展名：xxx.json」 | 蓝奏白名单没有 .json | 把这个文件放进 .zip 再发布 |
| 「网盘把 X 改名成了 X(1).zip」 | 云端有同名残留没删干净 | 刷新后重试；仍失败去网页版手动删 |
| 「上传失败（HTTP 404）」 | 接口变了 | 升级程序 |
| 「账号未激活，请先激活后使用云存储」 | 蓝奏账号没激活 | 去官网激活 |
| 「上传失败：容量不足」 | 免费账号额度满了 | 清理云端旧文件 |
| 「读取云端 manifest 失败」 | 分享被关 / 网络 | 程序会退回上次缓存，可继续发布 |
| 「云端目录可用：False」 | 账号掉线 | 重新认证 |

**诊断**：详情 → 概览 → **诊断**，会逐条检查：云端路径 / 账号认证 / 云端目录。

## 8. 发布检查清单

发布前逐条过一遍：

- [ ] 本地枪包能正常进游戏
- [ ] 单文件 < 100MB
- [ ] 没有 `.json` / 没有奇怪扩展名
- [ ] 版本号改过了
- [ ] 更新说明写了
- [ ] 需要的话填了「最低程序版本」
- [ ] 发布后把「分享信息」发给玩家

## 9. 教程动画分镜建议

**第 0 幕 · 开场（3s）**
- 画面：主界面，侧边栏身份卡特写「玩家」
- 文案：「想把预设发给别人？先切到开发者」

**第 1 幕 · 认证（6s）**
- 高亮：侧边栏「切换身份」
- 动作：点 → 弹窗弹出（弹簧）→ 输入账号密码 → 点「登录并切换」
- 画面：侧边栏徽标变成「开发者」，下面打出 `186****9816`
- 文案：「一次认证，之后自动登录」

**第 2 幕 · 云端路径（5s）**
- 高亮：卡片「绑定」按钮
- 动作：点 → 弹窗 → 输入 `/PulsesSwap/SSR预设包` → 保存
- 文案：「填一个云盘路径，不存在会自动建」

**第 3 幕 · 扫描（4s）**
- 画面：卡片圆点从灰变橙 + 呼吸，第三行出现「有 3 项待发布」
- 文案：「只传变化的文件」

**第 4 幕 · 发布（8s）**
- 画面：发布框，逐行出现差异（错开 60ms）
- 特写：版本号、更新说明、最低版本三个输入框
- 动作：点「预演」→ 摘要弹窗 → 关掉 → 点「开始发布」
- 文案：「manifest 最后才换，传一半失败也不会发坏」

**第 5 幕 · 分享（5s）**
- 画面：进度 100% → 「发布完成」
- 动作：点「复制分享信息」→ 顶部浮出「分享信息已复制」
- 文案：「一条消息发给玩家，收工」

**第 6 幕 · 收尾（3s）**
- 画面：卡片回到绿色「云端已是最新」+ 详情里的发布记录
- 文案：「Pulses Swap · 开发者端」

**动效参数**同玩家端文档第 10 节。
