# 更新日志

## v2.7.7（2026-10-25）

### 收窗起点修正
- 关闭动画不再使用启动时保存的 `_window_final_rect`，改用窗口**当前**矩形：用户移动或缩放过窗口后，收窗从当前位置直接下移淡出，不会先跳回启动位置。
- 最大化/最小化状态只做 alpha 淡出，不写 geometry，避免关闭时把最大化窗口先还原。
- `window_anim_check` 增加「移动窗口后关闭仍从当前位置收窗」断言。

### 版本
- 版本 2.7.7；动画效果与 2.7.6 相同，仅修正收窗起点。

## v2.7.6（2026-10-25）

### 窗口出现 / 关闭动画
- 主窗口不再硬切：出现时从最终位置下方 26px、全透明开始，320ms 快速上浮淡入，并带约 2px 的轻微回弹；关闭时下移 18px、210ms 淡出，动画结束后才真正隐藏并退出。
- 参考 PCL 的窗口动效，但按 Tk 的能力做了取舍：**只动 y 和 alpha，不逐帧缩放窗口尺寸**。Tk 改一次 geometry 尺寸就会重排整棵控件树，大界面上会明显掉帧；纯位移不触发内部重排。
- 启动时先让 Tk 画出 alpha=0 的起始帧，再启动补间，避免首次布局把前几帧吞掉后窗口“突然以半透明出现”。
- 开窗/关窗期间暂停 Win11 不透明防护，防止 `<Configure>` / `<Map>` 回调把 alpha 拉回 1.0；动画结束再统一刷新窗口不透明。
- 关闭入口统一走 `request_exit`：同步/发布中仍然拒绝退出，关闭动画期间重复点击不会重入。
- 修复隐藏（withdraw）状态下 `winfo_width()` 恒为 1，居中按 1x1 计算导致窗口显示后偏半个窗口的问题；用启动时保存的 `_initial_size` 兜底。

### 验证
- 新增 `tests/test_window_motion.py`：几何解析、中心缩放、矩形插值、补间首帧语义，共 8 个用例。
- 新增 `packaging/window_anim_check.py`：验证出现时透明且位于下方、结束后回到最终矩形、关闭时单调淡出并隐藏。
- 单元测试 194 个全部通过；`ui_audit`、`ui_process_check`、`anim_invariants`、`scale_check`（100/125/150）、`scroll_check`、`startup_check`、`online_ui_check`、`online_e2e` 全部通过。

## v2.7.5（2026-10-25）

### 交互过程修复
- 修复卡片、差异清单、侧栏云端行、管理页预设行的真实鼠标命中：
  CustomTkinter 的 `bind()` 只绑内部 Canvas，点在 `CTkLabel` 的文字上时事件落在内部 `Label`，此前会出现“看得见但点不到/悬停不亮”。新增统一的事件目标绑定。
- 修复卡片 hover 的 `NameError`：`C_INPUT_BG` 未导入；同时按 EventType 枚举判断 Enter，真实鼠标事件不再被当成 Leave。
- 修复卡片 flash/入场动画完全不可见：卡片之前 `border_width=0`，却一直只改 `border_color`；现在保留 1px 同色描边，动画期间才浮出强调色。
- 修复展开侧栏后点导航收起又立刻被 hover 弹开；收起时记录“指针还在侧栏内”，要求指针真正离开后才能再次 hover 展开。
- 修复侧栏空态仍创建滚动容器导致首次展开卡顿：云端列表改为有数据时才创建，空态直接移除。
- 收起侧栏时只保留图标栏并卸载内容，避免 292px 内容跟着每帧重排导致掉帧；展开时再恢复。
- 修复侧栏每次展开重复 `lift()` 触发整栏重绘；改为装配时抬一次。
- 修复详情弹窗三个选项卡没有选中态：打开时显式选中当前页签。
- 修复弹窗首帧先居中再跳到 6% 处开始入场；现在第一帧就在动画起点。

### 文字及时性与文案
- Step 1「当前预设」和侧栏预设同步跟随当前选择，不再停在已应用的旧预设。
- 检查进行中隐藏旧的「同步 N 项更新」按钮，避免状态写着“连接中”却还挂着上次的更新数。

- 加载预设期间状态显示“加载中…”，完成/失败才切换为“已加载/加载失败”。
- 统一“未绑定来源”、TACZ 目录、中文省略号等文案；错误详情在卡片/来源页展示，右上角只留结论。
- 长预设名在 Step 1、侧栏、管理页、详情标题、云端行和 Toast 中截断或换行，不再撑破布局。
- 同一状态文字再次以 `progress=None` 调用时会清掉遗留进度条。

### 下载引擎
- 并发进度回调串行化并丢弃倒退值，进度只增不减。
- 增加中途取消、clone 会话、进度单调、真实 mock 多文件并发测试。

- 开发者未加载整合包即可登录蓝奏云并管理云端；账号文件改为本机公共存储，切换整合包/数据库不用重复登录。
