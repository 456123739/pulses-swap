# 更新日志

## v2.7.2（2026-10-22）

- 修复所有列表的滚动卡顿：
  - 卡片列表不再为每个滚轮事件重启 150ms 补间，直接走 Canvas 原生滚动；
  - 全局滚轮路由改为每个窗口只注册一次，不再 `unbind_all` 把设置页/管理页/侧边栏的 CTk 滚动绑定一起解掉；
  - tk.Listbox（枪包 / 最近）改回原生按行滚动，去掉反复取消/重开的补间；
  - 滚动期间暂停卡片 hover 过渡，入场动画最多只给首屏 8 张卡；
  - 新增 `packaging/scroll_check.py` 回归：多列表交替滚动、CTk 滚动不被解绑、Listbox、60 张卡片到底。
- 修复启动时先出现小窗口再展开：创建 Tk 后先 `withdraw()`，整套 UI 建好、布局完成、居中后再 `deiconify()`。
- 版本 2.7.2；2.7.1 为仅源码版本。

## v2.7.1（2026-10-22）

- 玩家同步预设默认改为**完全同步**：云端没有、本地多出来的枪包会被勾选删除，删除走系统回收站（不是永久删除）。
- 设置 → 在线同步 → 「同步方式」可改回「保留多余」；旧版本没有显式改过这一项的，升级后按新默认「完全同步」。
- 同步弹窗里会提前勾选本地多余枪包，并提示「会送进回收站」。
- 其余功能与 2.7.0 相同。

## v2.7.0（2026-10-21）

- 折叠侧栏底部显示**当前身份**：玩家 `Ply`（青色）/ 开发者 `Dev`（石板蓝），下方小字写全称；展开后显示「切换为开发者身份 / 切换为玩家身份」，标题对齐到目标选项上方。
- 云端 manifest 从 `_pulses_manifest.txt` 升级为 `_pulses_manifest.cfg`（**内容仍是 JSON**，只为绕开蓝奏扩展名白名单，schema 2）：每个枪包带 `sha256` / `packed_sha256`，整份 manifest 带 `manifest_sha256`；旧 `.txt` 仍可读，发布后自动迁移。
- `tacz_default_gun` / `tacz-default-gun` 在任意层级都不扫描、不打包、不进 manifest；TACZ 默认枪由游戏自己创建。
- 2.7.0 暂不构建 macOS；Release 只包含 Windows 绿色版 / 安装器和 Linux 版，源码包一并上传。
- 其余功能与 2.6.0 相同。

## v2.6.0（2026-10-21）

### 界面重构
- 侧边栏改为可折叠图标栏：折叠 60px，悬停展开 292px 浮层，不挤占工作区；展开时工作区压暗，移开自动收起。
- 新增「管理」页：全局预设总览（本地/云端/待处理）、预设行内动作、快捷操作、云端文件树、完整日志；设置页与管理页职责分离。
- 设置页改为左侧设置、右侧运行日志两栏；设置项紧凑分组，不再整行拉满；新增「完整更新前确认」。
- 玩家/开发者身份改为滑动开关，配色、图标、动作区同步切换；玩家不显示开发者账号与云端文件入口。
- 主界面管理面板、加高整卡拖拽区、单行状态条、完整日志；预设空状态、菜单按钮、进度百分比等细节修复。
- 启动窗口居中；高 DPI 下自绘控件缩放修正。

### 功能与逻辑
- 开发者未加载整合包即可登录蓝奏云并管理云端；账号文件改为本机公共存储，切换整合包/数据库不用重复登录。
- 启动自动探测云端连通性；有绑定源/云端路径时自动检查更新（只检查，不自动下载/发布）。
- 管理页支持真实云端目录浏览、展开、上传文件/文件夹、新建文件夹；上传目标优先当前预设的云端路径，路径框可改。
- 玩家「全部更新」串行执行并二次确认；开发者「全部检查」；离线计划禁止发布/同步。
- 角色隔离补齐底层兜底：玩家不能发布，开发者不能下载/同步；上传/发布入口与直接调用均有守卫。
- watchdog 改为 0.45s 防抖，同时监控 tacz 与当前预设目录；变更后后台重算索引并刷新。
- 文件扫描/网络请求/上传下载全部移出主线程；枪包扫描、默认预设创建、日志渲染均优化。

- 设置页首次打开显示成「数据库」页（SlideStack 初始化只摆当前页）。
- 预设列表初始空状态不显示；进度面板百分比 NameError 导致文字不更新。
- 发布角色越权兜底、离线计划发布/同步、详情条状态、换源缓存等既有修复保持。
