## v3.0.0（2026-10-30）

### 架构
- 新增 `feature/webview` 分支：UI 从 customtkinter 迁移到 **PyWebView 6.2.1 + React 19 + Vite + Motion**。

- 本地前端通过 PyWebView 内置 HTTP server 加载，不使用 CDN；DND 走 `window.dom` 的 `pywebviewFullPath`，支持文件夹路径。
- Windows 使用 WebView2，安装器随包提供 Bootstrapper；PyInstaller 打包前端 `dist` 和 WebView2 依赖。

- 页面/身份切换保留完整 `Pulses Swap` 长字标幕布；身份切换在幕布下完成主题和可用操作更新。
- 按钮按压缩放、列表入场、Modal/Toast 弹簧、进度条单调平滑；`prefers-reduced-motion` 降级。
- 侧栏展开时内容区同步让位，避免 Tk 老版本中常见的文字裁剪。

### 验证

- `ui_process_check`、`anim_invariants` 等原有 Tk 回归继续保留；React 端 `test-ui.mjs` 检查首页/侧栏/幕布/设置/日志/DND/三档窗口尺寸，全部通过。

## v2.7.6（2026-10-25）

### 窗口出现 / 关闭动画
- 主窗口不再硬切：出现时从最终位置下方 26px、全透明开始，320ms 快速上浮淡入，并带约 2px 的轻微回弹；关闭时下移 18px、210ms 淡出，动画结束后才真正隐藏并退出。
- 参考 PCL 的窗口动效，但按 Tk 的能力做了取舍：**只动 y 和 alpha，不逐帧缩放窗口尺寸**。Tk 改一次 geometry 尺寸就会重排整棵控件树，大界面上会明显掉帧；纯位移不触发内部重排。
- 启动时先让 Tk 画出 alpha=0 的起始帧，再启动补间，避免首次布局把前几帧吞掉后窗口“突然以半透明出现”。
- 开窗/关窗期间暂停 Win11 不透明防护，防止 `<Configure>` / `<Map>` 回调把 alpha 拉回 1.0；动画结束再统一刷新窗口不透明。
- 关闭入口统一走 `request_exit`：同步/发布中仍然拒绝退出，关闭动画期间重复点击不会重入。
- 修复隐藏（withdraw）状态下 `winfo_width()` 恒为 1，居中按 1x1 计算导致窗口显示后偏半个窗口的问题；用启动时保存的 `_initial_size` 兜底。
