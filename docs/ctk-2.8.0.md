# Pulses Swap CTk 2.8.0 · 新 UI 功能同步

本版把 3.x（新 UI）已经验证的一键化功能同步回 customtkinter 桌面版，
保持现有 CTk 布局和视觉风格，只重排必要的一键操作入口。

## 默认自动化

- 玩家：**一键更新全部**，遍历所有已绑定预设；自动检查、下载/修复、按“完全同步”处理本地多余项，已应用预设会先收回、更新、再自动替换。
- 开发者：**一键上传全部**，遍历所有已绑定/已填云端路径预设；自动生成计划、递增补丁版本、上传变更；默认保留云端多余文件。
- 单个预设失败不阻塞其他预设；失败会自动恢复已应用状态，最后汇总成功、无需、失败数量。
- 手动“检查更新 / 同步当前 / 发布当前 / 选择差异 / 填版本号”默认折叠；设置里打开 **高级操作** 才显示。
- 同步方式、发布预览、完整更新确认也只在高级操作开启后显示；默认使用完全同步、直接发布、无二次确认。
- 从云端添加预设后自动检查并完整同步；不再第二次弹选择框。

## 共享执行器

- 新增 `src/pulses/auto_actions.py`，WebView 与 CTk 共用一键更新/发布逻辑：
  - 收回已应用预设 → 检查/计划 → 下载/上传 → 自动替换；
  - 自动版本递增（`v1.2.3` → `v1.2.4`）；
  - 离线计划拒绝自动发布；
  - 单个失败隔离并恢复 TACZ；
  - 取消后返回“已取消”，不误报成功。
- `_set_role()` 等核心接口保持同步；动画和进度只包在 UI 层。

## 稳定性修复

- 修复多线程并发读写 `sources.json` 时固定 `.tmp` 文件名互相抢占，导致
  `No such file or directory: sources.json.tmp` 的问题：写入改为唯一临时文件并加锁。
- 一键更新/发布期间暂停 TACZ watcher 的收回/重应用窗口，避免扫描到半截目录。
- 一键入口在没有绑定源时禁用；绑定后自动恢复。

## 验证

- 223 个 Python 单元/集成测试通过。
- `ui_process_check`：验证默认隐藏手动检查、高级开关显隐、一键按钮调用、身份幕布、页面幕布和收尾残留。
- `ui_audit`、`anim_invariants`、`scale_check`（100/125/150）、`scroll_check`、`startup_check`、`window_anim_check`、`online_ui_check` 全部通过。
- `online_e2e`（真实界面 worker + 本地蓝奏模拟）：发布 → 同步 → 改版 → 玩家一键更新全部 → 开发者一键上传全部 → 重启状态一致，全部通过。
