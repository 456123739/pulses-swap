# Pulses Swap CTk 2.8.1 · 一键化收口

这是 customtkinter 桌面版的补丁版本，重点不是加功能，而是把默认界面真正收成
「一眼就知道点哪里」的一键流程。

## 默认只保留

### 玩家
- 一键更新全部
- 下载预设
- 打开 TACZ（已配置时）
- 预设卡片 / 详情 / 云端状态

### 开发者
- 一键上传全部
- 打开 TACZ
- 云端路径
- 预设卡片 / 详情 / 云端状态

## 收进高级操作

打开「设置 → 在线同步 → 高级操作 → 开启」后恢复：

- 手动检查更新 / 同步当前 / 刷新
- 部分同步、发布前预览、完整更新确认、同步方式
- 版本号与说明编辑
- 开发者的「发布当前」与「一键替换」
- 管理页的当前预设同步、检查、刷新、清理缓存

默认关闭，不会留下隐藏按钮的空白占位；关闭后立即恢复简洁界面。

## 行为修复

- 「已是最新」时一键更新不再先收回再重新应用已应用预设。
- 发布计划没有上传项时同样不收回。
- 预设加载完成后刷新一键按钮状态，避免首屏灰按钮。
- 开发者默认首页不再出现「发布到云端」大按钮。
