# 业务修复验收记录

本轮基于 release/webui-3.2 的 207a464（3.3.4）修复。尚未将本轮改动发布为新绿色版。

## 已确认并修复

- **实际界面操作定位的根因**：上传任务持有 controller.lock 并等待 manifest-read 线程；网络线程写日志再次等待同一业务锁，导致请求成功却报 25 秒超时。改为独立日志锁和受锁保护的日志快照，保留真实日志链路验证，不屏蔽日志绕过。

- 禁止云端清单读取失败后回退历史清单，包括账号可浏览但分享页不可用的情况；旧 allow_cache/prefer_cache 参数仅保留兼容签名，不再启用回退。
- 检查到的 checked_version/checked_generation 与实际完成的 last_version/last_generation 分开；检查不再冒充同步完成。
- 发布和同步计划执行前复核本次实时云端与本地快照，内容变化或网络不可用立即拒绝。执行后消费计划，重新检查失败也不会遗留旧的可执行计划。
- 部分下载不提前推进整个预设版本；移入回收站失败明确记 failed；取消在安装及完成阶段检查。
- 上传初始化清单失败即停止；初始化清单作为回滚基线；末项完成后取消也清理未引用上传；清单删除/上传统一处于恢复保护内，恢复未确认明确报错。
- 控制器不再将失败/取消的条目强行标 same；changed 使用实际完成项数；blocked/min_app 不兼容不会被归为已是最新。
- 登录身份、发布计划归属、空勾选、部分失败/取消反馈、未绑定首传入口和跨计划选择状态均有防错。
- 云盘导航请求按序列与账号/数据库作用域隔离，旧响应不覆盖新目录；剪贴板不可用或分享地址为空明确报错。
- 删除绑定预设云目录及其祖先均受保护。
- 持久化历史检查不直接当作当前事实；任务事件早到会缓冲，丢失终态可通过 job.status 查询恢复。超时只警告，不允许后台旧任务尚未结束时启动并发写任务。

## 验证方法

- Python unittest 全套 **291 项通过**；最后的状态响应修正后聚焦控制器 **50 项通过**，包含失败、取消、部分选择、过期计划、任务终态查询及日志锁回归。
- 前端竞态回归覆盖早到事件、旧任务终态隔离、失败/取消识别、云盘乱序及任务轮询恢复。
- 原有 Playwright UI 与响应式布局测试。
- 实际 React 界面点击测试采用真实 Python Api/EventBus/JobRunner/Controller，底层为本机 HTTP 蓝奏模拟服务；仅桌面传输、测试账号服务地址和文件选择器使用测试适配。该结果不能称为真实蓝奏账号验证。

## 已通过的界面流程

证据见同目录下 web-ui/verification 的 SIMULATED 报告和截图。真实 React 页面点击开包、登录、切身份、新建预设、导入 alpha、指定云路径/版本/说明首传，随后导入 beta 并点击更新：远端 v2.3.4 → v2.3.5，generation 1 → 2；增量只传 beta 和清单，alpha 未重传。故障注入使本机模拟网盘清单 HTTP 字节损坏，尽管本地保存 v2.3.5 历史清单，上传仍明确失败；远端文件、哈希、上传与删除记录均不变。浏览器未出现页面错误。

## 验证边界

- 本轮没有登录或使用用户真实蓝奏账号，没有宣称已完成真实网盘首次绑定上传与第一次更新的验收。
- 第三方网盘不提供原子清单替换；断网导致恢复也失败时，只能明确报告并保留恢复信息，不能保证远端事务原子性。
- 正常业务入口产生的计划有实时快照；底层兼容人工构造 Plan 的旧调用不等于界面业务通路。
