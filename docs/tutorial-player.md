# 玩家端操作教程（v2.7.2）

> **v2.7.2 界面变化**：左侧是折叠图标栏，鼠标悬停展开（不挤占工作区）；
> 身份改为「玩家 / 开发者」滑动开关；新增「管理」页，集中放全局预设总览、
> 行内检查/更新/发布/绑定、快捷操作、云端文件树和完整日志。
> 设置页改为左侧设置、右侧运行日志两栏。开发者未加载整合包也可以先登录云端。


> 面向：只想用别人做好的枪包预设的玩家。
> 全程只需要「点」和「拖」，不需要碰命令行。
> 本文同时是**教程动画的脚本**：第 10 节给了分镜建议。

---

## 1. 开始之前

| 名词 | 意思 |
|---|---|
| 整合包 | Minecraft 整合包根目录，里面有一个 `tacz` 文件夹 |
| 预设 | 一组枪包的集合。切换预设 = 把这一组枪包换进 `tacz` |
| 云端源 | 预设绑定的网盘分享（蓝奏云链接 + 密码） |
| 同步 | 把云端比本地多出来 / 更新过的枪包下载下来 |

需要准备：

1. 一个整合包（含 `tacz` 文件夹）
2. 发布者给你的**分享链接**和**密码**（形如 `https://xxx.lanzoul.com/b0123456`，密码 4 位）

**侧边栏**：页面切换（主界面 / 设置 / 日志）+ 底部身份卡。

**右列**：枪包明细 + 日志，最下面是主操作「一键替换」。

### 预设卡片

每张卡片一行一个预设，结构固定：

```
● SSR预设包                                    [更新] [⋯] [已应用]
  v2026.10.18 · 24 个枪包 · 1.8 GB
  有 3 个更新 · 142.0 MB
```

- 左边圆点 = 状态（见第 7 节）
- 第一行 = 名称，右边是动作按钮 + 更多菜单
- 第二行 = 版本 · 枪包数 · 总体积
- 第三行 = 云端状态（没有绑源时显示「未绑定云端源」）
- **单击选中**，**双击打开详情**，**右键出菜单**

## 3. 流程 A：第一次使用（从零到能用）

### ① 选整合包

1. 点左列「① 整合包」里的 **选择**
2. 选中整合包根目录（里面能看到 `tacz` 文件夹那一层）
3. 成功后：路径显示为绿色，状态变成「已加载 ✓」

> 也可以直接把整合包目录（或其中任意文件）拖进那个虚线框。

### ② 从云端添加预设

1. 点「② 预设管理」下方的 **从云端**
2. 弹窗「从云端添加预设」里粘贴 **分享链接**
3. 填 **分享密码**（公开分享可留空）
4. 点 **读取并创建**

会发生什么：

- 程序读取云端的 manifest（几十 KB），拿到预设名、版本、文件数
- 自动在本地建一个同名预设
- 立刻开始检查，然后弹出同步框

如果提示「预设已存在」：说明本地已经有这个名字的预设，去它的卡片上点「绑定」填链接即可。

### ③ 同步（下载枪包）

同步框内容：

```
同步 · SSR预设包
云端 v2026.10.18 · generation 7
┌──────────────────────────────────────────┐
│ 下载 2 · 更新 1 · 一致 21      [全选][全不选] │
│ ☑ ● gun_alpha.zip        下载    41.9 MB  │
│ ☑ ● gun_beta.zip         下载    52.4 MB  │
│ ☑ ● gun_gamma.zip        更新    38.0 MB  │
│ ☑ ○ old_pack.zip     本地多余      3.2 MB  │
└──────────────────────────────────────────┘
云端说明：新增 3 把枪，修贴图
                                   [取消] [开始同步]
```

1. 默认已经勾好「下载 / 更新」项
2. 默认是**完全同步**：「本地多余」也会勾上，删除时走系统回收站
   （设置 → 在线同步 → 同步方式 → 「保留多余」可改回不删）
3. 点 **开始同步**

同步过程中会显示：

```
正在同步 · SSR预设包                            42%
[████████████░░░░░░░░░░░░░░░░░░░░]
[2/3] gun_beta.zip
12.4 MB / 30.0 MB · 1.8 MB/s · 剩余约 10 秒
                                        [取消]
```

- 每个文件下载完会**当场校验**（zip 比 sha256，文件夹包解压后比树摘要）
- 单个文件失败不影响其它文件，结束后会汇总告诉你哪几个失败
- 中途取消：已装好的保留，下次同步会接着补

### ④ 应用预设

同步完成后点右列最下方的 **一键替换**：

- 当前 `tacz` 里的枪包会被收回原预设
- 新预设的枪包会被放进去
- 按钮变成「已应用 ✓」，卡片上出现「已应用」标签

进游戏就能用了。

## 4. 流程 B：日常更新

发布者更新后：

1. 打开程序（如果设置里开了「启动时检查更新」，会自动查）
2. 卡片第三行出现「**有 3 个更新 · 142.0 MB**」，圆点变橙色并轻轻呼吸
3. 点卡片右侧的 **更新**（或右键 → 同步…）
4. 同步框里只勾中真正变化的文件 → **开始同步**

也可以点「② 预设管理」下方的 **检查全部**，一次检查所有绑定了源的预设。

> 想手动看一眼细节：双击卡片 → 详情 → 「概览」有差异摘要，「枪包」列出每个包的状态。

---

## 5. 流程 C：删掉不需要的枪包

发布者把某个枪包删掉后，你本地还留着：

1. 检查更新后，同步框里会出现「**本地多余**」的行（默认勾选）
2. 直接 **开始同步**，或先取消勾选保留它
3. 文件会被移到**系统回收站**（不是直接删除），删错了能找回来

## 6. 绑定 / 更换云端源

卡片右键 → **云端来源…**（或卡片上的「绑定」按钮）：

| 字段 | 说明 |
|---|---|
| 分享链接 | 必填，`https://xxx.lanzoul.com/bXXXXXX` |
| 分享密码 | 没有密码就留空 |
| 备用链接 | 可选。主链接失效时自动换过去 |
| 启动时自动检查更新 | 默认勾选 |

- 点 **测试连接**：显示「连接成功 · N 个文件 · X MB · 已发布」
- 点 **保存**：保存后立刻检查一次

## 7. 状态词典

卡片圆点 / 第三行文字 → 含义 → 该做什么：

| 圆点 | 文字 | 含义 | 操作 |
|---|---|---|---|
| 蓝 | 未绑定云端源 | 这个预设没绑源 | 点「绑定」填链接 |
| 灰 | 待检查 | 绑了源但还没查过 | 点「检查」 |
| 蓝（闪） | 检查中… | 正在读云端 manifest | 等一下 |
| 橙（呼吸） | 有 N 个更新 · X MB | 云端有新内容 | 点「更新」 |
| 绿 | 已是最新 · 3 分钟前 | 本地和云端一致 | 无需操作 |
| 绿 | 云端已是最新（开发者） | 云端和本地一致 | 无需操作 |
| 红 | 连接失败：… | 网络 / 密码 / 分享失效 | 点「重试」或改源 |
| 红 | 云端要求 Pulses Swap X 或更高 | 程序版本太低 | 升级程序 |

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 「分享密码错误」 | 密码填错 / 发布者改了密码 | 右键 → 云端来源 → 改密码 |
| 「分享已失效」 | 发布者取消分享 / 文件被删 | 找发布者要新链接 |
| 「连接失败：连接网盘失败」 | 网络不通 / 被拦截 | 换网络，点「重试」 |
| 「网盘要求人机验证」 | 当前网络被网盘风控 | 换手机热点，过几分钟再试 |
| 「磁盘空间不足：需要 X，只剩 Y」 | 空间不够 | 清理磁盘后重试 |
| 「校验不通过」 | 下载内容损坏（会自动重下一次） | 多次失败说明云端文件坏了，找发布者 |
| 「超过网盘单文件上限」 | 某个枪包 > 100MB | 让发布者分卷 |
| 同步完还是「有更新」 | 云端 manifest 没换（发布者上传失败） | 让发布者重新发布 |

**诊断**：双击卡片 → 概览 → **诊断**，会逐条告诉你哪一步不通：

```
诊断 · SSR预设包
✓ 状态目录可写      C:\...\PulsesSwap_database\.online
✓ 预设目录存在      C:\...\SSR预设包
✓ 磁盘剩余空间      182 GB
✓ 已绑定分享链接    https://nimshade.lanzoul.com/b0139mgt2j
✓ 分享链接可访问    24 个文件
✓ 云端 manifest 可读  v2026.10.18 · generation 7
```

## 9. 交互细节

| 操作 | 效果 |
|---|---|
| 单击卡片 | 选中，③ 详情更新 |
| 双击卡片 | 打开详情弹窗 |

## 10. 教程动画分镜建议

> 每一幕给：画面区域、高亮元素、文案、时长。

**第 0 幕 · 开场（3s）**
- 画面：整个主界面，缓慢推进（1280×900 → 1.05 倍）
- 文案：「Pulses Swap · 一键切换枪包预设」

**第 1 幕 · 选整合包（5s）**
- 高亮：左列 ① 区域（发光描边）
- 动作：鼠标点「选择」→ 文件对话框（可用占位）→ 路径变绿
- 文案：「第一步：告诉程序你的整合包在哪」

**第 2 幕 · 从云端添加（7s）**
- 高亮：② 区域的「从云端」按钮
- 动作：点击 → 弹窗从下往上弹出（弹簧，约 7% 过冲）
- 特写：粘贴链接 → 点「读取并创建」
- 文案：「粘贴发布者给的链接，剩下的交给程序」

**第 3 幕 · 同步（8s）**
- 画面：同步框，列表逐行出现（每行错开 60ms）
- 特写：勾选框状态、底部「已选 3 项，135.3 MB」
- 动作：点「开始同步」→ 切到进度视图
- 文案：「只下变化的文件，下载完当场校验」

**第 4 幕 · 应用（4s）**
- 画面：进度条到 100% → 弹窗收起 → 卡片闪光 → 圆点变绿
- 动作：点「一键替换」→ 按钮变「已应用 ✓」
- 文案：「一键替换，进游戏就能用」

**第 5 幕 · 日常更新（5s）**
- 画面：卡片圆点从绿变橙并开始呼吸
- 文案：「发布者更新后，卡片会自己亮起来」
- 动作：点「更新」→ 同步框里只有 1 项

**第 6 幕 · 收尾（3s）**
- 画面：三张卡片 + 右侧枪包列表全景
- 文案：「Pulses Swap · 玩家端」

**动效参数**（和程序里一致，动画里照抄即可）：

| 元素 | 曲线 | 时长 |
|---|---|---|
| 弹窗入场 | 阻尼弹簧，过冲约 7% | 280ms |
| 卡片选中描边 | 轻弹簧，过冲约 3% | 210ms |
| 按钮按下 / 松开 | 快沉 / 轻回弹 | 70 / 200ms |
| 状态点呼吸 | 明暗往复 | 1400ms 循环 |
| 列表滚动 | 三次曲线 | 150ms |
| 输入框聚焦 | 描边弹到强调色 | 200ms |

## 附：2.5.1 起的两处变化

- 点卡片上的「更新」= 直接下载并装好，**不再弹「要更新哪些文件」的选择框**。
  默认「完全同步」会删掉本地多余枪包（进回收站）；
  取舍放到「设置 → 在线同步 → 同步方式：完全同步 / 保留多余」。
- 进度条就在右侧「一键替换」按钮下面，替换和同步都走它；
  同步时还会额外弹一张进度卡，显示当前文件与速度。
