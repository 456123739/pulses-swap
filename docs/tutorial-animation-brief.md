# 给做教程动画的 AI：要点

> 这份不重复讲风格，只讲**去哪拿信息**、**哪些不能改**、**怎么对齐**。

---

## 1. 先读这三份

| 文档 | 拿什么 |
|---|---|
| `docs/tutorial-player.md` | 玩家端 6 幕分镜、每一步的按钮文案、状态词典、动效参数表 |
| `docs/tutorial-developer.md` | 开发者端 6 幕分镜、发布顺序、失败对照表 |
| `docs/swap-online.md` §14 | 视觉体系（三档层级色、圆角、间距、字号）、动效曲线表 |

界面本身长什么样，看 `tutorial-*.md` 里的 ASCII 布局图和「界面地图」小节；
每个按钮/标签的**准确文案**也在里面，动画里的字必须和它一致。

---

## 2. 界面信息从哪来

- **文案 / 状态 / 流程**：以两份 tutorial 文档为准（它们是从代码里抄出来的）。
- **精确坐标 / 颜色 / 字号**：跑 `python packaging/ui_snapshot.py out.json`，
  会把整棵控件树导成 JSON（路径、类名、文案、xy、宽高、颜色、字体）。
  想还原某个界面的真实排版，直接读这个文件，别靠猜。
- **真实截图**：本机（weston headless + Xwayland）拿不到像素 ——
  `XGetImage` / `CopyArea` 都会 BadMatch，`weston-screenshooter` 在 headless
  后端报 `width > 0` 断言失败。所以：
  **要么在普通桌面上自己截，要么用上面的 JSON 还原。**

---

## 3. 不能改的东西

1. **文案照抄**。包括全角标点、`·` 分隔、`…` 省略号、`✓`。
2. **不用 emoji，不用图标字体**。产品里刻意没有图标。
3. **不新增界面元素**。动画是"演示已有界面"，不是重新设计。
4. **数字要自洽**：卡片上写「24 个枪包 · 1.8 GB」，同步框里的合计就得对得上。
5. **顺序不能乱**：发布永远是「建目录 → 删云端多余 → 上传 → manifest 最后换」，
   动画里如果画成"先换 manifest"，就传达了错误的模型。

---

## 4. 动效参数（和程序一致，直接抄）

| 场景 | 曲线 | 时长 |
|---|---|---|
| 弹窗入场 | 阻尼弹簧，过冲约 7% | 280ms |
| 按钮按下 / 松开 | 快沉 / 轻回弹 | 70 / 200ms |
| 卡片选中描边 | 轻弹簧，过冲约 3% | 210ms |
| 侧边栏滑块 | 弹簧，过冲约 5% | 240ms |
| 列表滚动 | 三次曲线 | 150ms |
| 输入框聚焦 | 描边弹到强调色 | 200ms |
| 状态点呼吸 | 明暗往复 | 1400ms 循环 |
| Toast | 滑入 + 回弹 | 200ms 进 / 190ms 出 |

节奏建议：单幕 3–8 秒，转场不超过 400ms，全程不要有"匀速直线"的运动。

## 5. 配色（直接用，别调）

```
窗口底   #F5F7F8
卡片     #FFFFFF   描边 #E3EAEB
凹槽     #EDF2F4
强调     #5BA89A   悬停 #4A9285   按下 #3D7A6E   浅底 #D6E8E4
主文字   #2C3E3F   次要 #6B7B7D   极淡 #9AABAD
警告     #C9A961   错误 #C97B7B   信息 #7B9DC9
```

圆角：卡片 16 / 控件 12 / 进度条 4。
间距：卡片内 16×12，块之间 10，紧邻 6。

---

## 6. 每一幕要交代清楚的三件事

1. **点哪里**（高亮那个控件，其它地方压暗 20%）
2. **发生了什么**（列表逐行出现 / 圆点变色 / 进度推进）
3. **结果是什么**（卡片状态变了、按钮文字变了、弹窗收起）

只要这三件事清楚，风格和镜头可以自由发挥。

---

## 7. 建议的产出规格

- 1920×1080，60fps，H.264
- 中文旁白（可关），字幕用文档里的原话
- 结尾 2 秒留白放 logo（`packaging/icon.png`）

---

## 8. 容易画错的地方

| 别画成 | 应该是 |
|---|---|
| 同步 = 下载整个预设 | 只下变化的文件（差异列表里"一致"的项是灰的） |
| 点一下就开始传 | 中间有确认框，要勾选再点「开始同步」 |
| 发布 = 直接覆盖 | 先传文件，**最后**才换 manifest |
| 玩家端有"发布"按钮 | 玩家只有「更新」；开发者才有「发布」 |
| 失败 = 全盘失败 | 单个文件失败不影响其它，最后汇总 |
| 删除 = 直接删掉 | 本地多余文件进**回收站** |
