# 入口检查（3.2 开发线）

> 核对时间：2026-11-08。目的：确认每条主要功能在默认界面里都能**一眼看到、一次点到**，
> 不依赖右键菜单、控制台或“高级操作”里的隐藏项。
> 本轮按检查结果补了 4 个入口：预设条目「更新/上传」、主操作区「一键更新」、「一键上传」、详情卡「检查差异」。

## 一、玩家端

| 功能 | 入口 | 位置 | 备注 |
|---|---|---|---|
| 定位整合包 | 「选择整合包」/ 拖入 / 「切换」 | 首屏主卡 | 有最近打开下拉 |
| 从云端添加预设 | 「从云端拉取预设」 | 主操作区 | 次要按钮，常驻 |
| **一键替换** | 「一键替换」 | 主操作区主按钮 | 高度 52+，比次要按钮显眼；已应用时变为「已应用」状态块 |
| **一键更新（当前预设）** | 「一键更新 N」 | 主操作区 | 本轮新增；只在当前预设已绑定时出现，N = 待下载/变更 + 多余 |
| **一键更新全部** | 「一键更新全部」 | 主操作区 | 已绑定预设 ≥ 1 时出现 |
| **预设级更新** | 预设条目右侧「更新 N」小按钮 | 预设列表 | 本轮新增；`needs_update` 时才出现（检查过且有待处理项） |
| 检查差异 | 「检查差异」 | 详情卡底部 | 本轮新增；绑定后常驻，可先看差异再决定更新 |
| 查看枪包差异 | 枪包列表按状态上色 + 图例 | 详情卡 | 本轮新增：缺失（蓝）/ 变更（金）/ 多余（玫红）/ 一致（灰绿） |
| 切换/重命名/删除预设 | 点行 / 悬停行内按钮 / 右键详情 | 预设列表 | 右键 = 详情弹窗 |
| 打开 TACZ | 「打开 TACZ」 | 详情卡底部 | |
| 管理云端文件 | 「管理云端」 | 详情卡底部 | 跳管理页 |
| 登录 / 切换身份 | 侧栏底部身份按钮 | 侧栏 | 未登录时点身份 → 登录弹窗 |

## 三、通用

| 功能 | 入口 |
|---|---|
| 设置（同步方式 / 自动检查 / 动画 / 高级操作） | 侧栏「设置」 |
| 日志 | 侧栏「日志」 |
| 切换数据库 | 设置页 → 数据库 |
| 清空日志 | 日志页 |
| 帮助 / 关于 | 侧栏底部 |

## 四、这轮补的入口（合计 4 处）

1. 预设条目「更新 / 上传 N」小按钮 —— 需要处理时才出现，点一下直接跑该预设的一键流程。
2. 主操作区「一键更新 N」—— 玩家端，针对当前预设。
3. 主操作区「一键上传 N」—— 开发者端，针对当前预设。
4. 详情卡「检查差异」—— 绑定云端后常驻，先看差异再更新。
