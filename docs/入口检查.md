# 入口检查与一键化（3.2 → 3.3 迭代）

> 2026-11-15。方法：一个独立审计员按「玩家 / 开发者 × 全部业务」逐条走查代码与界面，
> 输出问题清单（P0–P3），再按清单改；改完用 Playwright 断言 + 截图逐项复核。
> 本文是改完后的现状，不是计划。

## 一、这一轮解决的核心问题

| 问题 | 现在 |
|---|---|
| 新用户不知道该点哪 | 主页顶部常驻**「下一步」引导条**：按状态给一句话 + 一个按钮（定位整合包 / 新建预设 / 一键更新 / 一键替换） |
| 不常用的按钮看不懂 | 每个关键控件旁边有 **「?」**：悬浮/聚焦/点一下，出现一句人话（不带术语） |
| 新建预设是空壳，没有加枪包入口 | 详情卡「导入枪包」+ 空列表里的按钮；`preset.import` 复制文件进预设，同名跳过 |
| 已应用的预设不能再替换 | 主按钮变成 **「已应用 · 重新替换」**，可点 |
| 上传到云端是个死胡同 | 管理页新增 **「云端文件」页签**：浏览 / 面包屑 / 新建文件夹 / 上传 / 容量 |
| 绑错了没法撤 | 绑定卡片新增 **「解除绑定」**（本地文件不动） |
| 失败消息 3 秒就没了 | 错误提示常驻 9 秒，带 **「重试」**；网络类错误**自动重试一次** |
| 弹窗先关再执行，失败要重填 | 失败时弹窗不关，错误就地显示，已填内容保留 |
| 绑定完不知道下一步 | 绑定时自动检查一次云端，直接出差异 |
| 动手点多，容易并发 | 有任务在跑时拒绝新任务并提示，避免结果丢失 |
| 已绑定但没更新提示 | 预设行常驻「更新/上传」小按钮（不再只在 needs_update 时出现） |
| 云端连不上只知道转圈 | 离线时显示「用的是上次缓存」的说明条 |

## 四、自动处理（用户不用自己排查）

1. 网络抖动：任务失败自动重试一次，提示「网络不太稳，正在自动重试…」；仍失败给「重试」按钮。
2. 离线：检查退回上次缓存，界面标明「用的是缓存」；发布拒绝用缓存计划。
3. 更新已应用预设：自动「收回 → 检查/下载 → 再替换」，失败也会把 tacz 恢复。
4. 绑定后自动检查；导入后自动刷新预设与枪包列表。
5. 上传/下载/发布都有进度、可取消；单文件失败不拖垮整批，最后汇总。
6. 并发保护：上一个任务没结束，新操作会被拦下并提示。

## 五、动效（苹果式阻尼弹簧）

- 统一弹簧令牌：`SPRING(430/34)`、`SPRING_SOFT(260/30)`、`SPRING_SNAP(620/38)`。
- 枪包行：悬浮放大 1.022 + 上浮 1.5px + 跟随鼠标的高光；按下 0.988；状态色条与阴影同时亮起。
- 预设行：名字哈希生成稳定强调色（连续色相、低饱和），左侧色条随悬浮/选中伸展；
  悬浮放大 1.015 + 上浮 + 柔光；选中状态用同色淡底。
- 尊重「界面动画」开关：关掉后不做位移与光斑，只保留状态色。
